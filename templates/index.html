1. Listar todo: GET http://127.0.0.1:5000/api/lista 2. Buscar por nombre o artista: GET http://127.0.0.1:5000/api/buscar?q=DI BOWNS GET http://127.0.0.1:5000/api/buscar?q=SARCASMO 3. Descargar el archivo: GET http://127.0.0.1:5000/descargar/NOMBRE_ARCHIVO.srt 🐍 Código Python completo: import requests BASE = "http://127.0.0.1:5000" # 🔍 Buscar consulta = "SARCASMO SIN AUTOTUNE" resp = requests.get(f"{BASE}/api/buscar?q={consulta}") datos = resp.json() if datos["encontrados"] > 0: cancion = datos["resultados"][0] print(f"✅ Encontrado: {cancion['artista_original']} — {cancion['cancion_original']}") # ⬇️ Descargar descarga = requests.get(f"{BASE}{cancion['ruta']}") with open(cancion["archivo"], "wb") as f: f.write(descarga.content) print(f"💾 Guardado como: {cancion['archivo']}") else: print("❌ No encontrado")
